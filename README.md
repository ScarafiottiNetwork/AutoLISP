# Scarafiotti Network - AutoLISP

AutoLISP routines developed for AutoCAD automation and technical design workflows.

This repository reflects part of the engineering and CAD automation experience developed by **Scarafiotti Network** and Cristian Scarafiotti through decades of work in electrical and multidisciplinary building-services design.

## Background

Since 1988, Cristian Scarafiotti has worked in technical and engineering environments, primarily in electrical-system design and in close coordination with professionals responsible for:

- electrical systems
- HVAC and mechanical systems
- air distribution systems
- fire protection systems
- technical building infrastructure

Automation has always been an important part of this activity.

AutoLISP was used to reduce repetitive CAD operations, standardize drawings and improve productivity in AutoCAD-based technical workflows.

## Scope

This repository is intended to contain selected AutoLISP routines for activities such as:

- drawing automation
- object and block manipulation
- layer management
- repetitive CAD operations
- drawing standardization
- technical drafting utilities
- data extraction and processing

## Repository status

This repository is being progressively organized and documented.

Some routines originate from long-term internal use and may require modernization, documentation or adaptation before publication.

Customer-specific drawings, standards and proprietary project information are not published.

## Compatibility

AutoLISP routines may have been developed for different AutoCAD generations.

Compatibility with current Autodesk AutoCAD releases should therefore be verified before production use.

## Disclaimer

Always test routines on copies of drawings before using them on production files.

The code is provided without warranty unless otherwise explicitly stated.
